# Brand assets — drop the dino-nugget image here

This folder holds the app's logo / cover art (the little dino-nugget mascot that
currently shows as the 🦖🍗 emoji).

## How to add the image

1. Put your image file in **this folder** named exactly:

   ```
   dino-nugget.png        (preferred: PNG; a JPG named dino-nugget.jpg is fine too)
   ```

   Easiest via GitHub web: open this `assets/brand/` folder on GitHub →
   **Add file ▸ Upload files** → drag the image in → **Commit**.

2. Tell me it's uploaded. I'll then:
   - **cut out the background** (make it transparent) and save it as
     `dino-nugget-cut.png` here,
   - wire it in as the **logo/mascot**, replacing the 🦖🍗 emoji on the
     welcome, generate, model-setup, and drawer screens,
   - (optional) set it as the **app icon + splash** in `app.json`.

## Notes
- Higher resolution is better (≥ 512×512, square-ish framing works best for an
  icon). A plain/solid background cuts out most cleanly.
- Until the real image is added, the app keeps using the 🦖🍗 emoji so nothing
  breaks.
